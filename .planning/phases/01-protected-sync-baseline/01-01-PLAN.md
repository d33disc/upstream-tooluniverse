<interfaces>
The script is a caller-supplied-target orchestrator: implementation code may live at a newer commit while `--repo` points at the isolated worktree for the pinned pre-sync fork OID. `--repo` and `--worktree-dir` are common required arguments. This plan implements the disposable command shape `capture_sync_baseline.py --repo <repo> --worktree-dir <worktree> --output-dir <output>` and rejects `--ci-evidence`, `--publish-root`, or `--result-json`; Plan 01-04 extends the same parser with a mutually exclusive final mode requiring all three final flags and forbidding `--output-dir`. All Git commands are argv arrays with explicit cwd, captured stdout/stderr, and no shell interpolation. JSON artifacts use sorted keys, two-space indentation, and a trailing newline.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repository and remote metadata → parser | Branch names, paths, modes, link text, and remote refs are untrusted byte-oriented input. |
| Original checkout → isolated worktree | User-owned tracked and untracked state must not cross into synchronization mutations. |
| Symlink entry → filesystem target | A link can escape the repository, point to missing content, or redirect traversal. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | Git subprocess boundary | high | mitigate | Use fixed argv arrays, explicit cwd, full OIDs, exit checking, NUL-safe parsers, and no shell execution in `run_git`. |
| T-01-02 | Tampering | Original checkout isolation | high | mitigate | Capture before/after snapshots and perform all target operations in a detached secondary worktree. |
| T-01-03 | Information Disclosure | Symlink inventory | high | mitigate | Use link blobs, `lstat`, and `readlink`; reject traversal and never recursively open target content. |
| T-01-04 | Repudiation | Preservation classification | medium | mitigate | Record source command, modes, object IDs, class, and rationale for every delta path; block unresolved classes. |
| T-01-SC | Tampering | Package installation | low | accept | No package installation occurs; the plan uses Git, uv, project dependencies, and Python stdlib only. |
</threat_model>
