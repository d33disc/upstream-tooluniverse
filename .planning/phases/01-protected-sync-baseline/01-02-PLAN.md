<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tool/provider output → normalization | Remote and local payloads may be malformed, volatile, large, or secret-bearing. |
| Process environment → evidence | Credential values are available for execution but forbidden from persisted artifacts. |
| Temporary evidence tree → published bundle | Incomplete or modified artifacts must not acquire a green status. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Information Disclosure | Provider diagnostics | high | mitigate | Serialize names/booleans only, redact before persistence, bound output, and scan all publishable bytes for configured values. |
| T-01-06 | Tampering | Normalization rules | high | mitigate | Exact-path allowlists plus invariant/schema checks preserve structural and semantic differences. |
| T-01-07 | Denial of Service | Live providers | high | mitigate | Three total attempts, fixed 2-second delay, per-attempt timeout, overall deadline, and no retry for permanent classes. |
| T-01-08 | Tampering | Evidence publication | high | mitigate | Validate a temporary tree, require every stage, publish atomically within a bounded root, and verify sorted SHA-256 entries. |
| T-01-09 | Repudiation | Catalog/provider selection | medium | mitigate | Record fork seed, candidate counts, selected names, credential-family mappings, and every attempt outcome. |
| T-01-SC | Tampering | Package installation | low | accept | No package installation occurs; existing project dependencies and stdlib are sufficient. |
</threat_model>
