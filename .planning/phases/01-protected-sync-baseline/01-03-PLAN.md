## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-10 | Spoofing | Surface certification | high | mitigate | Assert the concrete entry point/process/client and transport-specific handshake before accepting probe results. |
| T-01-11 | Information Disclosure | Child stdout/stderr | high | mitigate | Capture streams separately, bound and redact before persistence, and pass credentials only via inherited environment. |
| T-01-12 | Denial of Service | MCP/REST child lifecycle | high | mitigate | Loopback-only binding, free-port allocation, monotonic startup/operation/teardown deadlines, and terminate/kill cleanup. |
| T-01-13 | Tampering | Schema-to-execution link | high | mitigate | Derive executed arguments from the same surface's inspected schema and assert stage ordering in integration tests. |
| T-01-14 | Repudiation | Cross-surface result matrix | medium | mitigate | Record surface, tier, tool, stage outcomes, exact command/method names, durations, and sanitized diagnostics. |
| T-01-SC | Tampering | Package installation | low | accept | Existing MCP, FastMCP, FastAPI, Uvicorn, pytest, and stdlib facilities are used; no install task exists. |
