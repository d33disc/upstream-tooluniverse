Build the isolated integration stage that criterion 1 requires: a detached worktree at the pre-merge fork parent `e0755067`, with upstream `56adcfd9` merged into it and every conflict re-derived independently under D-08's resolution rule. Only an independently re-derived merge can answer that, and only an isolated stage can answer it without the main checkout's pre-existing dirty state contaminating the comparison.
