# Williams Style Guide

Condensed from Joseph M. Williams, *Style: Lessons in Clarity and Grace*.
Apply these rules to every sentence in the review.

## Core Principles

### 1. Characters as Subjects

The subject of every sentence should be a real character -- a person, gene,
drug, pathway, or entity that acts. Never let abstractions or nominalizations
occupy the subject position.

### 2. Actions as Verbs

Express the key action as the main verb. Eliminate nominalizations (nouns
derived from verbs). They bloat sentences and hide agency.

| Nominalization | Verb |
| --------------- | ------ |
| investigation | investigate |
| regulation | regulate |
| demonstration | demonstrate |
| association | associate |
| observation | observe |
| characterization | characterize |
| determination | determine |

### 3. Old Before New

Start each sentence with information the reader already knows (old). End
with the new information. This creates forward momentum.

### 4. Stress Position

Place the most important information at the end of the sentence. The reader's
attention peaks at the period. Never bury the key finding mid-sentence.

### 5. Consistent Topic Strings

Each paragraph should have one topic (usually one entity). If the topic
shifts sentence-to-sentence, the paragraph feels incoherent. Rewrite so
the same character appears as subject throughout.

### 6. Problem-Solution Framing

Structure each section as: (1) state the problem or gap, (2) present the
evidence, (3) deliver the conclusion. The reader should feel the question
before receiving the answer.

## Sentence-Level Rules

- Delete "it is/was" + "there is/are" constructions. Find the real subject.
- Delete "the fact that" -- always rewritable.
- Prefer active voice. Use passive only when the agent is unknown or
  deliberately de-emphasized.
- One clause per idea. If a sentence has 3+ clauses, split it.
- Cut hedge words: "somewhat", "relatively", "it could be argued that".
  State the claim directly, qualify with evidence tier.
- No throat-clearing: "It is important to note that", "It should be
  mentioned that", "Interestingly". Delete and start with the content.

## Paragraph-Level Rules

- First sentence: topic + claim.
- Middle sentences: evidence supporting the claim.
- Last sentence: implication or transition to next paragraph.
- Max 6 sentences per paragraph.
- One topic per paragraph. If the topic changes, start a new paragraph.

## Before / After Examples

### Example 1: Nominalization

BEFORE: "The investigation of TP53 mutations by several groups led to the
demonstration that loss-of-function variants are associated with
Li-Fraumeni syndrome."

AFTER: "Several groups investigated TP53 mutations and demonstrated that
loss-of-function variants cause Li-Fraumeni syndrome."

### Example 2: Buried Stress

BEFORE: "PARP inhibitors, which exploit synthetic lethality in
BRCA1-deficient cells, have shown clinical benefit in several phase 3
trials for patients with ovarian cancer."

AFTER: "In BRCA1-deficient ovarian cancer, PARP inhibitors exploit
synthetic lethality -- a mechanism validated across multiple phase 3 trials."

### Example 3: Topic Shift

BEFORE: "EGFR mutations drive NSCLC. Osimertinib targets the T790M
resistance mutation. Clinical trials demonstrated 18-month PFS. The FDA
approved it in 2018."

AFTER: "EGFR mutations drive NSCLC, and the T790M resistance mutation
remained untreatable until osimertinib. In phase 3 trials, osimertinib
achieved 18-month progression-free survival, earning FDA approval in 2018."

## Scientific Writing Specifics

- Gene symbols in italics: *TP53*, *BRCA1*.
- Protein names upright: p53, BRCA1 protein.
- Define abbreviations at first use; never in titles or abstracts.
- Numbers: spell out one through nine; use numerals for 10+.
- Use "respectively" only when listing parallel items in matching order.
- "Data" is plural: "these data show", not "this data shows".
- "Significant" means statistically significant. For importance, use
  "substantial", "notable", or "marked".
